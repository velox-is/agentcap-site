agentcap

Local-first observability and hard budget control for AI agents.

Point any agent's base URL at a local proxy. Every request is counted, priced and checked against a cap; a breach closes the stream and marks the task dead. Nothing leaves the machine — no account, no cloud, no telemetry.

npx agentcap init
npx agentcap start

TASK=$(npx agentcap task new --name my-run --max-tokens 200000)
# then send x-agentcap-task: $TASK
  • Per-task caps on tokens, steps, USD and wall clock, enforced mid-stream.
  • Late usage from OTel spans is applied and marked, never dropped.
  • Loopback only. Refuses to bind elsewhere.
